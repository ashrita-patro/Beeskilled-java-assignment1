📝 Assignment 1: Basic Calculator

Description

A console-based calculator that accepts two numbers and an arithmetic operator from the user.

Features

- Addition ("+")
- Subtraction ("-")
- Multiplication ("*")
- Division ("/")
- Division-by-zero validation
- Invalid operator handling

Concepts Covered

"Scanner", variables, data types, arithmetic operators, "switch", and "if-else".

📝 Assignment 2: Grade Evaluation Program

Description

A Java program that accepts student marks and displays the corresponding grade using conditional statements.

Grading Criteria

Marks| Grade
90–100| A
75–89| B
50–74| C
0–49| Fail

Features

- Accepts student marks as input.
- Evaluates grades using "if-else-if".
- Validates marks between 0 and 100.

Note: The grading criteria are used for this practice project and can be adjusted to match the internship requirements.

🏦 Mini Project: Bank Management Console App

Description

A basic menu-driven banking application that allows users to perform simple banking operations through the console.

Features

- Deposit money
- Withdraw money
- Check account balance
- Validate deposit and withdrawal amounts
- Prevent withdrawals exceeding the available balance
- Display a menu until the user exits

Concepts Covered

"Scanner", "do-while", "switch", conditional statements, variables, and arithmetic operations.

Initial Balance

The application starts with a sample balance of 1000.00.

Note: This is an educational console application, not a real banking system. Account data is not saved permanently.

▶️ How to Run the Programs

Prerequisites

- Install the Java Development Kit (JDK).
- Configure Java in your system.
- Open the project folder in VS Code or another Java IDE.

Step 1: Clone the Repository

git clone https://github.com/ashrita-patro/Beeskilled-java-assignment1.git
cd week-1-java-internship

Replace "https://github.com/ashrita-patro/Beeskilled-java-assignment1.git" with your GitHub repository URL.

Step 2: Compile and Run the Calculator

javac BasicCalculator.java
java BasicCalculator

Step 3: Compile and Run the Grade Evaluation Program

javac GradeEvaluation.java
java GradeEvaluation

Step 4: Compile and Run the Bank Management App

javac BankManagement.java
java BankManagement

Make sure the terminal is opened in the directory containing the Java files.
